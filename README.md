# gta6_rust_qwen_38_flash_next

A **headless, deterministic, dependency-free procedural city** in Rust — the simulation and
geometry substrate of a GTA-style open world, built as a workspace of small DDD-style
*bounded contexts*. One seed in, a whole city out: streets, lanes, traffic lights, zoned
blocks, buildings, parks, street lights, a day/night cycle, plus the pedestrian and vehicle
agents that move around it.

There is **no renderer yet**. Everything right now is CPU-side data + a GPU-ready vertex
format, verified by tests instead of screenshots.

- 9 crates, ~6.4k lines of Rust
- **0 external crates** (`Cargo.lock` contains only the 9 workspace members)
- **97 unit tests, all passing**
- Single commit history, and **almost nothing is committed yet** (see [Status](#status))

## Crate tour

### `gta-math` — 750 lines, 26 tests

Hand-written linear algebra, zero deps, pure (no I/O, no globals, no allocation).

- `Vec2 / Vec3 / Vec4` generated by `impl_common!` + `impl_slice_ops!` macros
  (`dot`, `normalize`, `lerp`, `min/max`, `map`, full operator set, `AsRef<[f32]>` for free
  byte access).
- `Quat` (axis-angle, `mul`, `rotate`, `slerp`), `Mat4` **column-major** `c[col][row]`,
  `translate / scale / rot_y / rot_x / compose(T,yaw,S) / mul / invert` (affine-only
  inverse), `perspective` (wgpu 0..1 depth) and `look_at`.
- `Aabb`, `Rng` (splitmix64), `noise` (value, Perlin, fBm, ridged, `Noise2`/`Noise3`).
- Helpers: `clamp`, `lerpc`, `wrap_angle`, `damp` (frame-rate independent smoothing).

Conventions: **right-handed, +Y up, −Z forward**, metres, `Vec2` holds `(x, z)`.

### `gta-geo` — 16 tests

The shape vocabulary shared by city, vehicles and characters.

- **`tri.rs` — the one vertex layout.** `Vertex` is `#[repr(C)]`, asserted at compile time
  to be **64 bytes** (`const _: () = assert!(size_of::<Vertex>() == 64)`), uploaded verbatim.
  It is deliberately *not* a conventional material:

  | field | meaning |
  |---|---|
  | `pos`, `normal` | geometry |
  | `color: [u8;4]` | albedo rgb; **`a` = specular strength** |
  | `emissive: [u8;4]` | emissive rgb; `a` = emissive gain, 0..255 → 0..8× |
  | `params: [f32;4]` | `x` = `FacadeKind`, `y` = bay width, `z` = storey height, `w` = night-lit probability |
  | `uv: [f32;2]` | surface coords in metres (along-face / up), not object space |
  | `_pad: [f32;2]` | padding to a clean 64-byte stride |

  Encoding the *recipe* per vertex is what lets **one shader draw every material** —
  asphalt, glass, chrome, skin, neon — and every facade in the city. `FacadeKind` =
  `CurtainWall | FrameGrid | Masonry | Shopfront | CarPark | None`.
- `MeshBuilder`: `tri`/`tri_n`/`quad`/`quad_n` **auto-correct winding to match the supplied
  normal**, so callers only have to get the normal right. Plus `merge_offset`, `merge_mat`,
  `apply`, `Paint` (finish, glow, lit chance, facade params).
- `primitives.rs` — 21 builders: `box_solid`, `box_walls`, `extrude_polygon`,
  `tapered_cylinder`, `cone`, `sphere`, `ellipsoid`, `blob`, `capsule`, `beam`, `wheel`,
  `chamfered_box`, `extrude_profile`, `octagon`, `inset`, … Real bevelled geometry, not debug cubes.
- `grid.rs` — `GridIndex<T>`, a uniform spatial hash (`insert`, `query_ids`, `query_exact`,
  `nearest`). Chosen because every runtime query is local and it needs no rebuild while agents move.
- `clip.rs` — Sutherland–Hodgman `clip_polygon` against a `Rect`, plus `area_abs`,
  `centroid`, `bounds`. Output stays convex → triangulation is a fan.

### `gta-city` — 42 tests, the biggest crate

The **simulation-level** model. Knows nothing about triangles or GPUs; answers
*"what is here?"*, *"where may a pedestrian walk?"*, *"which lane do I drive in?"*.
`scene` is what will turn it into triangles.

`generate(CityParams) -> City` runs once, then `City { params, network, walk, blocks }`
is read-only for the lifetime of the sim.

| module | contents |
|---|---|
| `params.rs` | `CityParams` — all knobs (`grid`, `block`, `road`, `avenue`, `avenue_every`, `sidewalk`, `kerb`) + `lines()`, `width(i)`, `rng(salt)` |
| `roads.rs` | `Axis`, `Road`, `Intersection`, `Network` — lanes per direction, `lane_offset`, `next_crossing`, `on_road(p, pad)`, light phases |
| `zone.rs` | `Zone` (`Downtown`, `MidRise`, `LowRise`, `Residential`, `Park`, `Plaza`, `Parking`) → floor height, floors envelope, site coverage, tree density; `Facade` → bay, glazing, night life |
| `blocks.rs` | one lattice cell → lots → buildings (`Building`, `RoofKind`) + `Tree`, `Lamp`, ponds; sidewalk ring → walk nodes; `add_crossings` |
| `graph.rs` | `WalkGraph` — sidewalk / crossing / plaza / park-path nodes, `link`, `link_ring`, `nearest`, `next_step`, `bfs_depth`, `unreachable_from` |

Defaults: `grid 11`, `block 46 m`, `road 12 m`, `avenue 20 m`, `sidewalk 3.4 m`, `kerb 0.14 m`.

Driver-side convention: a driver's right hand is `Vec2::perp` of travel, so `+X` traffic
occupies the `+z` half of the corridor and `−X` the `−z` half — two-way streets can never
overlap by construction.

### `gta-agents` — 758 lines, **currently not compiled** (TODO-01)

`traffic.rs`
- `Car { pos, yaw, speed, limit, length, width, tint, heavy, braking, turn, handled }`
- `Traffic::spawn/step/pose`, `Traffic::green(axis, t, phase)`
- **Not a physics sim.** A car is a point mass with a length. Steering = *"aim at a
  look-ahead point on my lane, turn towards it at a limited yaw rate"* — stable at any dt,
  keeps cars in lane, and sweeps through a turn arc with no special-case junction geometry.
  Handles queueing behind the car ahead, red lights, yielding to peds in the junction ahead,
  and turn decisions made **once per junction** (`handled` sentinel, `NAN` = none).
- `yaw_of` / `dir_from_yaw` deliberately agree with `Vec3::from_yaw` so the renderer can
  rotate a car mesh with the same number the sim uses.

`crowd.rs`
- `Ped` / `PedPose { stride, tint, height, ... }` (`stride` is the walk-cycle phase the
  renderer swings legs from), `Crowd::spawn/step/pose/in_junction`.
- Steering = hold a goal node, follow the shortest path, steer around whoever is in the way.
- **Jaywalking is impossible by construction**: crossings are the only edges between opposite
  kerbs, so a walker that won't step into traffic just waits at the kerb.

### `gta-sky` — 13 tests

CPU-side atmosphere only. `SkyParams` (`day_length`, `start_hour`, `noon_lean`, `haze`,
`cloud`, `night_lights`) → `Sky { sun_dir, sun_color, sun_intensity, ambient_sky,
ambient_ground, horizon, zenith, fog_density, night, stars, exposure, hour }`.
Time is a wall-clock hour on a 24 h clock; the sun runs a tilted circle (not an ephemeris —
it only has to look right). `night` (0 = day, 1 = night) is what switches windows and street
lights on; `horizon` doubles as the fog colour so geometry dissolves into the sky.

## Design decisions

**Determinism is the religion.** Everything is a pure function of `Params + seed`.

- `Rng` is splitmix64; `f32()` consumes the **top 32 bits** of the 64-bit stream, so output
  is bit-identical on any IEEE-754 `f32` platform (wasm32 and x86/AArch64 alike).
- **Salted streams per subsystem** (`params.rng(0x20_1F)` for zoning) and **one stream per
  block** (`0xB10C_5EED ^ (index * 0x9E37_79B9_7F4A_7C15)`) — adding a random consumer in one
  subsystem can never perturb another's output, and a change in one block never ripples into
  its neighbours. A test asserts byte-for-byte reproducibility of a whole city.
- Noise is allocation-free and seed-parameterised so the city can be regenerated identically.

**Tests are the specification.** They assert invariants, not smoke coverage:

| test | guarantees |
|---|---|
| `blocks_sit_between_their_kerbs` | block rects are exactly kerb-to-kerb |
| `buildings_stay_inside_their_block` / `buildings_do_not_overlap` | no building escapes or intersects |
| `props_never_land_on_a_carriageway` | no tree on the road, lamps stay on the kerb |
| `walk_graph_is_connected` | zero orphan walk nodes (BFS) |
| `sidewalk_nodes_are_off_the_carriageway` | pedestrians start off the road |
| `crossings_cross_a_single_street` | no crossing spans two streets |
| `downtown_is_taller_than_the_suburbs` | zoning produces a readable skyline |
| `generation_is_deterministic` | same seed ⇒ identical city |

**Geometry model.** `gap_i = block + (w_i + w_{i+1}) / 2` — consecutive centre lines are
spaced by the block plus *half of each adjacent corridor*, so the buildable kerb-to-kerb
distance is always exactly `block` however the street widths vary. This is why blocks use
`cell_centre()` and **not** the midpoint of the two centre lines: where an avenue meets a
normal street, the kerb midpoint sits `(w_i − w_{i+1})/4` off the line midpoint.

## Conventions

Recorded here because they are the parts most likely to cause sign errors.

| topic | rule |
|---|---|
| units | metres everywhere |
| handedness | right-handed, **+Y up**, **−Z forward** |
| `Vec2` | holds **`(x, z)`**, *not* `(x, y)`, throughout city/agents |
| matrices | **column-major** `Mat4::c[col][row]`; `as_slice()` is uniform-buffer ready |
| depth range | 0..1 (wgpu) |
| yaw | `0` ⇒ `+Z`, increasing towards `+X` (`Vec3::from_yaw`); `traffic::yaw_of` agrees so the renderer can rotate a car mesh with the same number |
| normals | outward-facing |
| `base` vs `centre` | `base` is the bottom of a solid, `centre` is the middle of the volume |
| road `along` / `cross` | `Axis::along_of` / `cross_of` project onto / across the street corridor |
| traffic side | driver's right is `Vec2::perp` of travel ⇒ opposite directions occupy opposite halves |
| winding | `MeshBuilder::tri_n` / `quad_n` auto-correct to the given normal — only the normal matters |

## Data flow

```
CityParams { seed }
   │
   ├─ params.lines() ─────────► Network::build ──► roads, lanes, intersections(+phase)
   ├─ ZonePlanner (rng 0x201F) ─► Zone per block
   ├─ per-block rng stream ─────► blocks::build ──► lots, buildings, trees, lamps
   └─ sidewalk rings ───────────► WalkGraph ─────► + zebra crossings
                                        │
                    Traffic::step ──────┤   (lane following, lights, yielding)
                    Crowd::step ────────┘   (path + steering avoidance)
                                        │
     Sky::at(hour) ──► uniform          ▼
              [ MISSING: scene → render ]  ◄── Vertex / Paint / FacadeKind ready for GPU
```

## Gotchas

1. **`gta-agents` compiles nothing.** `crates/agents/src/lib.rs` is `//! placeholder` with no
   `mod traffic; mod crowd;`. Both files — 758 lines, and the only place `GridIndex` is used
   for anything real — are silently excluded from the build graph and have 0 tests.
   `cargo build -p gta-agents` "succeeds" while testing nothing. → `TODO-01`
2. **Vertex stride is documented three ways.** `geo/src/lib.rs` says "packed 32-byte vertex",
   `tri.rs` says "48-byte stride", the real `VERT_STRIDE` is **64** (compile-time asserted).
   → `TODO-02`
3. **Dangling doc references.** `tri.rs` and `sky.rs` reference the `render` crate consuming
   them; `render`/`scene` are empty. Docs promise a pipeline that doesn't exist yet. → `TODO-04`
4. **`panic = "abort"` in release** breaks `cargo test --release` conventions; run tests in
   the default profile.
5. **`MeshBuilder` winding auto-correction** means you only ever have to get the *normal*
   right — do not also try to fix winding by hand, or you will double-flip.
6. **`Vec2` is `(x, z)`, not `(x, y)`** everywhere in city/agents. Easy source of sign errors
   when mixing with `Vec3`.
7. No CI config, no LICENSE file, no rust-toolchain pin despite `edition = "2021"`.
